# React State Management Examples

Small side-by-side JavaScript and TypeScript examples for learning React state management.

1. Local state — `useState`
2. Lifting state up — shared state in the closest common parent
3. Derived state — calculate values instead of duplicating state
4. `useReducer` — explicit transitions for complex local state
5. Context — share a dependency through a component tree
6. Zustand — shared client-side state
7. Server state — TanStack Query for remote data
8. URL state — Next.js search parameters for shareable filters

Each folder contains `javascript/` and `typescript/` versions.
